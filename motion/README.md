# Мульт-истории для TikTok/Reels — рецепт

Формат по референсу (`ref/ref.mp4`): вертикальный 2D-мультик, закадровый голос, короткие рубленые фразы
в настоящем времени, крупные субтитры капсом с толстой обводкой, «интерфейсные» вставки (чат, уведомления,
пузыри с биркой имени), в конце — выбор «Что ты сделаешь?» и плашка с телефоном доверия + «ЧАСТЬ 2».

### Как собрано
- `kira/js/chars.js` — персонажи (Кира, мама) и телефон в SVG, плоский стиль с толстым контуром.
- `kira/js/scenes.js` — вёрстка 10 сцен; `kira/js/timeline.js` — камера, моргание, взгляд, дыхание, вибрации, счётчики, звук.
- `kira/js/words.js` — слова голоса с таймкодами (распознаны и выправлены) для субтитров.
- Рендер: движок motion-director, `mo render kira --out out/kira_full.mp4`.

### Новый ролик по шаблону
1. Сценарий 100–120 слов (≈45 с голоса): хук-факт → эскалация с цифрами → дом/взрослый → кульминация-угроза → выбор зрителя.
2. Озвучка в ElevenLabs (eleven_v4, Egor), скачать mp3 в `media/`, распознать `asr`, поправить слова → `js/words.js`.
3. Переставить сцены и тайминги в `scenes.js` / `timeline.js` по таймкодам слов.
